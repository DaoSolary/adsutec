# Instruções para Imagem de Fundo da Hero Section

## Localização
Adicione a imagem de fundo no diretório: `adsutec/public/`

## Nome do Arquivo
O arquivo deve se chamar: `hero-bg.jpg`

## Especificações Recomendadas
- **Formato**: JPG ou PNG
- **Tamanho**: 1920x1080px ou maior (para alta qualidade)
- **Peso**: Otimizado (recomendado < 500KB para melhor performance)
- **Aspecto**: Paisagem (landscape)

## Conteúdo da Imagem
A imagem deve:
- Ser relacionada ao nicho de tecnologia (circuitos, códigos, dispositivos, arquitetura moderna, etc.)
- Enaltecer Angola (paisagens, arquitetura moderna angolana, elementos culturais, etc.)
- **NÃO** conter rostos de pessoas
- Preferencialmente destacar elementos de raça negra de forma positiva
- Ter boa qualidade e profissionalismo
- Combinar bem com o tema do site (tecnologia e inovação)

## Exemplos de Temas
- Arquitetura moderna de Luanda
- Paisagens angolanas com elementos tecnológicos
- Circuitos eletrônicos com cores da bandeira de Angola
- Edifícios modernos com tecnologia
- Elementos abstratos tecnológicos com cores vibrantes

## Como Adicionar
1. Coloque a imagem no diretório `adsutec/public/`
2. Renomeie para `hero-bg.jpg`
3. A imagem será carregada automaticamente

## Nota
A imagem terá um overlay gradiente azul para garantir boa legibilidade do texto sobre ela.
